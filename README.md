# 市场观察

一个本机运行的 A 股 / 港股研究工作区：首页先看关注列表和重点变化，进入个股后查看研究时间线、走势图、财报新闻和观察笔记。

## 启动

Windows 已安装项目依赖时，双击 **打开网站.cmd** 即可在默认浏览器打开网站。本机服务会在需要时自动启动。

需要 Python 3.12。已经有 `.venv` 时，也可以在项目目录运行：

```powershell
.venv/Scripts/python.exe -m backend
```

或运行 `./start.ps1`。打开 **http://127.0.0.1:8765/**。端口被其他程序占用时可用 `--port 8766`。

新环境安装：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.lock.txt
Copy-Item .env.example .env
```

已有 `.env` 时不要覆盖。`DEEPSEEK_API_KEY` 可选；缺少或接口失败时仍保存并展示规则解读。

程序运行期间才能更新数据。首次启动自动采集；此后交易时段每 10 分钟检查一次，盘前 08:00 起采集、收盘后的数据校验通过后生成复盘。周末、假日不做盘中检查。关闭终端或电脑后更新停止，已保存的报告不会丢失。`STOCK_AGENT_AUTO_REFRESH=0` 可关闭自动采集，改为页面手动更新。没有安装系统计划任务、开机服务，也不会发送飞书消息。

## 日常使用

- **市场切换**：顶部 HK 港股 / CN A股拨片切换关注列表、币种、交易状态、报告和笔记。
- **管理股票**：点击关注列表旁的“管理”，输入代码即可添加；港股可省略前导 0，A 股使用完整 6 位代码。自动核验名称并开始采集，重复添加不会产生两份记录。移除后保留笔记与历史，重新添加可恢复。
- **今日总览**：看自选股价格、真实数据日期、重点事件；可筛选有变化或未查看的股票。
- **个股档案**：看近 30 / 60 / 120 个交易日价格、MACD / KDJ 图表与解读、技术状态、研究时间线和财报新闻。
- **新闻精选**：默认“重要”，也可选“财报”或“全部”。按财报业绩、经营数据和重大事项排序，日常回购合并；日期用于同等重要度排序和时效筛选，不再直接截取最前面的几条新闻。
- **历史日期**：查看该日的报告和不晚于该日的最近一次快照。没有保存过的数据不会假装存在。
- **观察笔记**：填写后点击保存，存入本机数据库；不会发送给 AI。
- **更新失败**：保留上次成功的数据；进入个股点击“更新这只股票”可补跑。
- **模拟交易**：侧栏进入虚拟账户，顶部切换市场。A 股初始 100,000 人民币、港股初始 100,000 港元，互不借用资金。每个账户分别点击“启动模拟”，运行期间收盘后检查一次新的交易日；“暂停模拟”取消未成交订单并阻止尚未完成的模型方案入账。

模拟账户使用现有 DeepSeek 配置。Agent 可以选择调用 `read_stock` 读取当前关注列表或已有持仓的资料，再通过 `submit_plan` 提交结构化方案；程序检查资金、仓位、每手股数与数据日期后才接受模拟订单。没有密钥、资料过期或模型失败时保留记录，不会用规则文案冒充 AI 交易。

第一版为日线模拟：方案生成完成后的下一个交易日开盘价加固定滑点，等当天收盘日线到齐后记账。单只上限 20%、总仓位上限 80%、最多 5 只，仅做多。A 股每边模拟综合费用 0.10%、港股 0.20%，最低各 5 元/港元；滑点分别 0.05% / 0.10%，开盘偏离决策参考价超过 3% 则到期。费用是实验假设，不是券商实际收费表。某些港股一手成本超过仓位上限时会保持观察。

**决策日志**保存当时的资料、工具查询、理由和验证条件；**模拟成交**保留已成交、拒绝、取消和到期记录；**复盘**在卖出或决策满五个交易日时记录结果。复盘当前是事实与待验证问题整理，不自动归因、修改代码、训练模型或声称策略已经改进。检测到持仓分红、拆并股时暂停账本，等待后续公司行动支持；不会静默计算错误收益。详见 [模拟账户口径](docs/paper-trading.md)。

`config.yaml` 和 `config.a.yaml` 的关注列表只在各市场首次启用网页管理时导入一次，之后以本机数据库为准，在网页管理即可，无需重启。即使清空列表也不会在重启后重新导入。两份配置仍管理分析参数与模型。报告从网站版首次运行开始积累；旧飞书正文没有历史存储，未自动导入。

GitHub 盘中模式在电脑关机后继续采样，决策和成交写入私有账本。安装方法及交易时段见[模拟交易云端部署](docs/cloud-paper.md)。

## 代码放在哪里

```text
backend/               唯一的业务后端
  app.py               HTTP 接口、本机访问边界、页面托管
  service.py           数据采集、报告流水线、后台更新
  store.py             SQLite 存储
  watchlist.py         股票代码规范化与名称核验
  news.py              新闻候选检索、重要度排序与去重
  market.py            A / H 交易日历、代码和币种
  prices.py            各数据源统一的行情校验
  data.py              行情源适配（复用旧版）
  fundamentals.py      港股财报与通用新闻
  a_fundamentals.py     A 股财报适配
  analyzer.py          技术计算（复用并修正旧版）
  indicators.py        MACD / KDJ 序列和规则解读
  reports.py           事件判断和可离线运行的规则解读
  llm.py               DeepSeek 文案接口
  fetch_worker.py      数据源超时隔离
  paper.py             双市场虚拟账本、交易检查、日线撮合与复盘
  paper_agent.py       有界工具调用与结构化模拟方案
  paper_data.py        独立成交价格、公司行动与港股交易单位
frontend/              无需单独安装或构建的页面
  app.js               路由和交互状态
  views.js             页面视图
  api.js               后端接口
  markets.js           市场路由、币种与股票标识
  watchlist.js          网页关注列表管理
  news.js               新闻重要度筛选与列表
  paper.js              模拟账户、决策依据和复盘视图
  format.js, chart.js   文本与价格图
  indicators.js        指标图表与简短解读
  styles.css           布局和组件样式
  tokens.css           颜色和字体变量
tests/                 关键回归检查，使用独立的合成测试数据
docs/                  架构与数据口径
data/                  本机数据库；不提交 Git
```

一个 Python 进程同时提供页面、接口和调度，只需维护一套应用。前端没有另一份股票分析逻辑，也没有浏览器中的第二份业务数据库。不要使用多个 Uvicorn worker，否则会重复启动调度。

`requirements.txt` 记录直接依赖范围，`requirements.lock.txt` 固定本次验证的依赖版本。升级后重新检查再更新锁定文件。

## 验证

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
node tests/frontend.test.mjs
```

Python 检查不调用外部行情/AI，不接触实际业务数据库。Node 仅用于开发检查，日常运行网站不需要 Node。

## 数据与备份

港股存储 `data/stock-agent.sqlite3`，A 股存储 `data/stock-agent-a.sqlite3`。关闭程序后备份这两个文件；运行中不要只复制主文件，因为 SQLite 可能还有 WAL 文件。`.env` 保存私密配置，不在网页中提供，也不提交 Git。可使用 `STOCK_AGENT_DB` / `STOCK_AGENT_A_DB` 分别指定持久文件，两者不能指向同一文件。

当前版只监听 `127.0.0.1`，仅供本机试用。远程部署时再统一增加认证和部署配置；不要直接将这个本机接口开放到公网。
